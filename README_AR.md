# إصلاح مسار AI في فطن

## ما تغير
- الفحص اليدوي للرابط مع عنوان الصفحة يستخدم /api/analyze ويجمع أدلة الهوية مع تحليل Gemini، بدل التحويل إلى /api/browser-check الذي قد لا يستدعي النموذج.
- رفع مهلة محاولة النموذج من 6 إلى 25 ثانية ضمن ميزانية 45 ثانية للطلب، مع إبقاء البدائل المحددة في إعدادات الخادم.
- إظهار أسباب فشل AI منفصلة: صلاحيات، حصة، نموذج غير متاح، صيغة طلب، رد غير صالح، أو مهلة/شبكة، دون كشف المفتاح أو نص الأخطاء الخام.
- تصحيح تسمية المحرك في نتيجة الفحص لتمييز التحليل الفعلي عن القواعد المحلية.
- تجهيز نسخ الواجهة في الجذر وفي static حتى يعمل GitHub Pages وFlask.

## الرفع
1. فك ضغط Fatin_AI_Fixed.zip وارفع محتوياته إلى جذر مستودع مشروعك الحالي، واستبدل الملفات المتطابقة مع الحفاظ على باقي مجلدات المشروع.
2. ارفع app.py وapp.js وstatic/app.js معًا. بقية الملفات ضمن الحزمة تحافظ على بنية التشغيل.
3. أمر البناء: pip install -r requirements.txt
4. أمر التشغيل: gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 60
5. أبقِ GEMINI_API_KEY في الخادم. عنوان خادم الواجهة الافتراضي الموجود في الكود هو https://fatin.onrender.com؛ إذا كان خادمك مختلفًا حدده من الإعدادات.
6. لم تُغيّر أسماء النماذج أو إعدادات ربطك. إذا ظهرت رسالة نموذج غير متاح، اضبط GEMINI_MODEL إلى نموذج متاح لحسابك واضبط GEMINI_FALLBACK_MODELS حسب الحاجة.
7. بعد اكتمال نشر الخادم حدّث الواجهة بـ Ctrl+Shift+R. افحص رابطًا مع عنوان صفحة، ثم رسالة ثم صورة ثم المستشار. نجاح AI يُعرف من engine=gemini في الرد، وليس من ai_configured وحده.

## التحقق وحدوده
اجتاز التعديل 15 اختبارًا محليًا باستخدام pytest ومكتبة Google الفعلية للتحقق من صيغة الإعدادات، مع محاكاة اتصال Gemini. اختُبرت أدلة الهوية، طلبات النص والصورة والمستشار، البدائل، أسباب الأخطاء والموافقة وملفات الواجهة. كما فُحصت صياغة JavaScript وPython.
لم تُنفذ طلبات Gemini حية ولم يتم نشر التعديل على GitHub أو Render. الاختبارات لا تثبت جودة اكتشاف التصيد أو توفر نموذج بعينه لحسابك.
الحالات التجريبية الثابتة في صفحة التجربة تبقى محلية عمدًا. لم تتضمن المرفقات مجلد إضافة المتصفح؛ الحزمة لا تستبدله ولا تنشئ إضافة جديدة.
لتشغيل الاختبارات: pip install pytest ثم python -m pytest -q tests
