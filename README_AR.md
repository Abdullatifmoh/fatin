# درع فطن — نسخة الهاكثون

تطبيق عربي متجاوب مع خادم Flask وتكامل Gemini، مستلهم من فصل الواجهة والخادم في التطبيق المرجعي المرفق. لا يحتوي على مفاتيح أو أسرار من المرجع.

## ما الذي يعمل؟

- تحليل بنية الروابط، أو نص رسالة/إيميل، وتفسير مؤشرات الاشتباه بالعربية.
- زر تفعيل وإيقاف الحماية يتواصل مع إضافة Chrome/Edge عند تثبيتها وضبط رابط اللوحة فيها.
- الإضافة تفحص عنوان الموقع العام في التبويب النشط، وتعرض تنبيهًا أعلى الصفحة عند اكتشاف مؤشرات. لم تُفتح الروابط على الخادم ولم تُرسل محتويات الصفحات أو المدخلات.
- رفع TXT وEML وCSV وJSON وHTML وLOG، حتى 20000 حرف، وتحليل المحتوى النصي.
- رفع صور PNG/JPG وPDF حتى 5 ميجابايت: يحتاج تحليل محتواها إلى Gemini. عند غياب الاتصال تظهر نتيجة غير حاسمة بدل ادعاء الفحص.
- بصمة SHA-256 للملف دون تشغيله أو تخزينه.
- مستشار Gemini يجيب عن أسئلة الأمن السيبراني ويحصل، بموافقة المستخدم، على سياق آخر فحص. لا يحتفظ الخادم بالمحادثة.
- حفظ ملخصات نتائج الفحص محليًا باختيار المستخدم، وإمكانية مسحها.
- إعداد مسودة تقرير قابلة للتحرير والنسخ والتنزيل، وفتح قناة الإبلاغ الرسمية. لا يوجد إرسال تلقائي أو تكامل مباشر أو شراكة مع الهيئة.

## تشغيل سريع — Windows

افتح PowerShell داخل مجلد المشروع بعد فك الضغط:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$env:GEMINI_API_KEY="ضع_مفتاحك_هنا"
$env:GEMINI_MODEL="gemini-2.5-flash"
.\.venv\Scripts\python app.py
```

ثم افتح http://127.0.0.1:5000 في Chrome أو Edge. إذا أردت تجربة القواعد الأولية دون Gemini، تجاوز سطر مفتاح Gemini. لا يوجد مفتاح مضمن في الملفات.

لا تكفي كتابة القيم داخل `.env.example`: التطبيق يقرأ متغيرات البيئة. الملف مرجع للإعداد فقط، ولا يُحمّل تلقائيًا.

## تشغيل سريع — macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
export GEMINI_API_KEY='ضع_مفتاحك_هنا'
export GEMINI_MODEL='gemini-2.5-flash'
.venv/bin/python app.py
```

## تثبيت إضافة حماية المتصفح

1. شغّل الخادم أولًا.
2. افتح `chrome://extensions` أو `edge://extensions`.
3. فعّل «وضع المطور» واضغط «تحميل إضافة غير مضغوطة».
4. اختر مجلد `extension` الموجود داخل المشروع.
5. افتح نافذة إضافة «درع فطن» من شريط المتصفح.
6. أدخل عنوان الخادم `http://127.0.0.1:5000` ورابط اللوحة نفسه.
7. إذا استخدمت `APP_ACCESS_TOKEN`، أدخل رمز الوصول نفسه في الإضافة وفي إعدادات اللوحة.
8. وافق على إرسال عناوين المواقع للفحص واضغط تفعيل الحماية، ثم امنح إذن المواقع الذي يطلبه Chrome.
9. أعد تحميل التبويبات التي كانت مفتوحة أثناء التثبيت، ومنها لوحة فطن.
10. زر الحماية في اللوحة يتحكم بالإضافة بعد تهيئتها. الإيقاف يزيل التنبيهات، ويتوقف إرسال العناوين الجديدة.

الإضافة لا تعمل على صفحات إعدادات المتصفح أو متجر الإضافات أو الملفات المحلية. تفحص التبويب النشط بعد تحميل الصفحة أو عند الانتقال إليه. لا تمنع تحميل الموقع أو إرسال النماذج، ولا تضمن صدور تنبيه قبل التفاعل. عند تعذر الاتصال يظهر × على أيقونتها، وتعرض نافذتها أن الفحص غير مكتمل.

## واجهة GitHub Pages وخادم منفصل

- ارفع محتويات `static` (index.html، style.css، app.js) إلى مستودع جديد مثل `fatin` على GitHub Pages. لا تحتاج لتغيير المستودع السياحي.
- انشر `app.py` و`requirements.txt` و`static` على خدمة تستضيف Python مثل Render، واضبط `GEMINI_API_KEY` في لوحة إعداداتها.
- أمر البناء: `pip install -r requirements.txt`.
- أمر التشغيل: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 60`.
- اضبط `CORS_ORIGINS=https://abdullatifmoh.github.io` أو أصل الواجهة الذي تملكه.
- افتح «الإعدادات» في فطن وأدخل رابط خادم HTTPS، ثم احفظ وتحقق من الاتصال.
- أدخل الرابط نفسه في إضافة المتصفح، واضبط «رابط لوحة فطن» على عنوان GitHub Pages الكامل، مثل `https://abdullatifmoh.github.io/fatin/`.
- احتفظ بمفتاح Gemini على الخادم فقط. لا تضعه في HTML أو JavaScript أو GitHub.

## حدود النموذج الأولي

التحليل يكتشف مؤشرات اشتباه، ولا يقدم شهادة سلامة أو نسبة خطر محسوبة. تصنيف «غير حاسم» يعني أن الفحص لا يكفي للحكم. قد تحدث إنذارات خاطئة أو تفوت تهديدات.

فحص الروابط يقرأ العنوان فقط، دون محتوى الموقع أو سمعة النطاق أو تحويلاته. فحص الملفات ليس مضاد فيروسات ولا Sandbox، ولا يدعم الوثائق المشفرة أو الأرشيفات أو الملفات التنفيذية. لا توجد قاعدة تهديدات خارجية أو Safe Browsing في هذه النسخة.

تُحذف معاملات الرابط وبيانات الدخول وجزء fragment قبل إرسال الرابط إلى Gemini. يحتفظ الخادم مؤقتًا بنتائج فحص عناوين المتصفح في الذاكرة لمدة خمس دقائق، دون كتابة على القرص. تُرسل الملفات المعتمدة إلى Gemini عند تفعيله؛ تعامل المزوّد مع البيانات يخضع لشروطه. لا تستخدم النموذج مع ملفات سرية.

حد الطلبات الحالي 20 طلب POST لكل دقيقة ولكل عنوان اتصال، وهو خاص بكل عملية خادم. للنشر العام واسع النطاق، أضف مصادقة مستخدمين، حد استخدام مشتركًا، مراقبة ميزانية Gemini، وفحص ملفات متخصصًا. `APP_ACCESS_TOKEN` بوابة اختبار اختيارية؛ لا يغني عن المصادقة الحقيقية. لا تُسجل مفاتيح أو محتويات الطلبات في أخطاء التطبيق.

الربط المباشر بالهيئة الوطنية للأمن السيبراني يحتاج اتفاقًا وقناة تكامل معتمدة. النسخة الحالية تجهز التقرير وتفتح الصفحة الرسمية فقط؛ لا تدّعي أن البلاغ أُرسل أو استُلم. صفحة الهيئة تتناول الإبلاغ عن حوادث الأمن السيبراني على الجهات الوطنية؛ راجع نطاق الخدمة قبل استخدامها.

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

اختُبرت قواعد الفحص، موافقة المستخدم، الملفات وحجمها، تقييد المصادر CORS، رمز الوصول، حد الطلبات، إزالة بيانات الرابط الحساسة، والتحول إلى نتيجة محدودة عند تعطل Gemini. استُخدمت استجابات Gemini بديلة لاختبار مسار التكامل؛ لم تُجرَ مكالمة حية دون مفتاح. اختبارات API لا تكفي وحدها لإثبات دقة كشف التهديدات.

## الملفات

- `app.py`: خادم API وتكامل Gemini.
- `requirements.txt`: Flask، flask-cors، google-genai، gunicorn.
- `static/`: الواجهة العربية المستقلة.
- `extension/`: إضافة Chrome وEdge.
- `tests/test_app.py`: اختبارات الخادم.
- `.env.example`: مرجع متغيرات البيئة.
- `Procfile`: مثال تشغيل خادم الإنتاج.

لتشغيل اختبار منطق الإضافة عند توفر Node.js: `node tests/test_extension.cjs`. صور الواجهة في مجلد `preview`.
