# درع فطن — النسخة 2.1 — الفكرة المدمجة

هذه حزمة جاهزة للرفع إلى مستودع فطن. لا تعني أنها نُشرت على رابط GitHub Pages أو Render تلقائيًا.

## رفع التحديث دون نسخ الكود

1. فك ضغط Fatin_Shield_V2.zip على الكمبيوتر.
2. افتح مستودع https://github.com/Abdullatifmoh/fatin واختر Add file ثم Upload files.
3. ارفع محتويات الحزمة إلى جذر المستودع، مع المحافظة على مجلدات static وextension وtests. استبدل الملفات المتطابقة. لا ترفع ملف ZIP نفسه، ولا تجعل المشروع داخل مجلد إضافي باسم fatin_v2.
4. اضغط Commit changes. Render يقرأ app.py وidentity.py وregistry.json وrequirements.txt من الجذر. الملفات الثلاثة الأولى لازمة؛ لا تستبدل app.py وحده.
5. GitHub Pages يقرأ index.html وapp.js وstyle.css وidentity.js الموجودة في الجذر. توجد نسخة مطابقة داخل static ليعرضها Flask.
6. في Render أبقِ Build Command: pip install -r requirements.txt
7. Start Command: gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 60
8. متغير CORS_ORIGINS: https://abdullatifmoh.github.io
9. أبقِ GEMINI_API_KEY داخل Render فقط. لا ترفعه إلى GitHub ولا تكتبه في إعدادات الواجهة. أبقِ GEMINI_MODEL وGEMINI_FALLBACK_MODELS كما ضبطتهما؛ توفر النماذج وحدود استخدامها يعتمد على حساب Google.
10. بعد ظهور Live، افتح https://fatin.onrender.com/api/health وتأكد من استجابة JSON. الموقع في GitHub Pages يستخدم الخادم افتراضيًا عند عدم وجود إعداد سابق. في إعداداته اختر عنوان الخادم https://fatin.onrender.com واترك رمز الوصول فارغًا إن لم تضبط APP_ACCESS_TOKEN.
11. حدّث الموقع بـ Ctrl+Shift+R. جرّب قسم «تجربة كشف الانتحال» ثم فحص رابط مع عنوان صفحة.

إذا فشل النشر، اقرأ آخر Traceback في Deploys. لا تنسخ الكود جزئيًا؛ ارفع الملفات كاملة.

## تشغيل الحماية في المتصفح

1. افتح chrome://extensions أو edge://extensions على الكمبيوتر.
2. فعّل وضع المطوّر، واختر تحميل إضافة غير مضغوطة، وحدد مجلد extension في الحزمة.
3. إذا كانت النسخة القديمة مثبتة، استبدل ملفات مجلدها بهذه النسخة ثم اضغط زر إعادة التحميل من صفحة الإضافات، أو ثبّت المجلد الجديد وأزل النسخة القديمة لتجنب تشغيل نسختين.
4. افتح نافذة الإضافة. الخادم: https://fatin.onrender.com، لوحة فطن: https://abdullatifmoh.github.io/fatin/
5. وافق على نطاق البيانات، وفعّل الحماية، ثم أعد تحميل التبويبات. زر الحماية في الموقع يعمل بعد تحديد رابط لوحة فطن في الإضافة.
6. الإضافة لا تعمل على chrome:// أو صفحات المتجر أو داخل متصفحات الهاتف التي لا تدعمها. تشغيل زر الواجهة وحده دون الإضافة لا يراقب التصفح.

## المنفذ الآن

- مقارنة اسم جهة في عنوان الصفحة أو أول أربعة عناوين h1/h2 مع نطاق مرجعي.
- جامعة الملك فيصل وسبل فقط، ونطاقاتهما الفرعية ضمن نطاق الفريق المدون.
- اكتشاف وجود حقول كلمة مرور أو دفع بأنواعها/خصائصها؛ لا تُقرأ قيم الحقول ولا ضغطات المفاتيح.
- تنبيه محلي، وإعادة فحص عند تغير الصفحة أو التركيز على حقل حساس. لا يحجب إدخال البيانات ولا يضمن الظهور قبل أول ضغطة.
- قناة رسمية ثابتة من القائمة، وليس رابطًا يختاره النموذج.
- شرح أدلة اختياري من Gemini؛ إذا تعذر يستمر التنبيه المحلي.
- تقرير قابل للتنزيل دون معاملات الرابط أو مساره في فحص التصفح. الحفظ في الواجهة اختياري ومحلي.
- ثلاث حالات عرض ثابتة معلّمة بأنها تجريبية؛ تعمل حتى دون خادم.
- فحص الرسائل والصور وPDF السابق مستمر لكشف مؤشرات التصيد؛ ليس فحص مضاد فيروسات.

## حدود لا يجوز عرضها كميزات مكتملة

- لا يوجد تحقق بصري من الشعارات أو الصور في إضافة المتصفح؛ قد يفوتها انتحال بلا اسم جهة في العناوين.
- النطاق المطابق لا يثبت سلامة الصفحة أو الحساب، واختلافه لا يثبت الاحتيال.
- قد تظهر إنذارات على موقع يذكر جهة بصورة عادية، أو مزود دخول خارجي مشروع لم يُراجع؛ يجب قياس ذلك على عينة مستقلة.
- لا تُفحص النماذج داخل إطارات خارجية أو Shadow DOM، ولا كل أنواع حقول الدفع المخصصة.
- القائمة لا تشمل جميع مزودي الدخول الخارجيين. إضافتهم تستلزم مراجعة رسمية مع توثيق المصدر.
- إزالة الأنماط الرقمية والبريدية من العناوين تقلل البيانات ولا تضمن إخفاء كل المعلومات الشخصية؛ لا تستخدم النموذج على صفحات عمل سرية.
- لا ربط تقني أو شراكة مع الهيئة الوطنية للأمن السيبراني، ولا إرسال بلاغات تلقائي. الموجود إحالة رسمية ومسودة للمراجعة.
- لا ضمان لاستمرار Gemini: حصة المشروع، المفتاح، الحساب، وتوفر الخدمة قد توقف جميع النماذج. Render المجاني قد يتأخر عند الاستيقاظ.

## التحقق المنفذ

اجتاز 24 اختبارًا آليًا للخادم، واختبار رسائل الإضافة، وتجربة الواجهة في Chromium على مقاسي الكمبيوتر والهاتف. شُغّل content.js في صفحة اختبار داخل المتصفح مع محاكاة رسائل Chrome للتأكد من ظهور التنبيه وعدم إرسال قيم حقول الدخول والدفع وإيقافه.

لم تُختبر نسخة الإضافة عبر تثبيت فعلي في Chrome على جهاز المستخدم، ولا طلبات Gemini الحية لهذه النسخة لعدم توفير مفتاح في بيئة التطوير. الاختبارات تستخدم بديلًا للنموذج لتختبر تبديل النماذج وحصر مدخلاته بالأدلة. لم يُقَس معدل اكتشاف التصيد أو زمن التنبيه على مجموعة مستقلة. صور preview للحالة المحلية، وليست إثبات نشر.

للتشغيل المحلي: pip install -r requirements.txt ثم python app.py.
للاختبار: python -m unittest discover -s tests -p 'test_*.py' ثم node tests/test_extension.cjs.

## تعديل القائمة

registry.json هو المصدر. بعد تغييره شغّل python sync_registry.py لتحديث identity.js داخل static وextension، ثم ارفع نسخ الواجهة الأربع في الجذر. أعد مراجعة اختبارات الانتحال والنطاقات بعد كل إضافة.
